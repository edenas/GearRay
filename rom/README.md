# Canonical generated ROM

Run `build.bat` from any working directory. It builds build/release with Release/profiling OFF and writes the ignored `rom/GearRay.gg`. The accepted ZV-01 image is 131,072 bytes, SHA-256 `B5F9DA2B5461574C6C09BC06387EEAA08AE304CAEEFC96F4FFCE1B7C2C58349B`. The frozen October image has a different historical identity.

Profile/dev/experiment outputs belong beneath their own build directories. The intentionally tracked historical October copy and manifest are in [artifacts/releases/2026-10-23](../artifacts/releases/2026-10-23/manifest.json). Historical ROM aliases and symbol/source dependencies are retained in [HISTORY](../docs/HISTORY.md), not as competing loose final ROMs. No tag or GitHub Release is created by the cleanup.
